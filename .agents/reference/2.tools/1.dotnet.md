# .NET

Use the project-specific commands below from the repository root.

## Restore

```bash
dotnet restore UI-Tweaks.sln
```

## Build

```bash
dotnet build src/UI-Tweaks/UI-Tweaks/UI-Tweaks.csproj
```

## Test

```bash
dotnet test tests/UI-Tweaks/UI-Tweaks.Tests/UI-Tweaks.Tests.csproj
dotnet test tests/GUI/BitzArt.VS.GUI.Tests/BitzArt.VS.GUI.Tests.csproj
```
