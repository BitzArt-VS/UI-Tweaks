# Project structure reference

Use the repository root as the working directory. The solution is defined by
[UI-Tweaks.sln](../../UI-Tweaks.sln).

| Area | Purpose |
| --- | --- |
| [`src/UI-Tweaks/UI-Tweaks/`](../../src/UI-Tweaks/UI-Tweaks/) | Production mod project targeting .NET 10. |
| [`src/GUI/BitzArt.VS.GUI.Abstractions/`](../../src/GUI/BitzArt.VS.GUI.Abstractions/) | GUI framework primitives and contracts that do not depend on its runtime implementation. |
| [`src/GUI/BitzArt.VS.GUI/`](../../src/GUI/BitzArt.VS.GUI/) | Cairo-backed GUI framework implementation and public components. |
| [`tests/UI-Tweaks/UI-Tweaks.Tests/`](../../tests/UI-Tweaks/UI-Tweaks.Tests/) | xUnit v3 tests with access to mod production internals. |
| [`tests/GUI/BitzArt.VS.GUI.Tests/`](../../tests/GUI/BitzArt.VS.GUI.Tests/) | GUI framework test project. |
| [`resources/`](../../resources/) | Vintage Story assemblies, mod metadata, localized assets, and textures used by build and packaging. |
| [`docs/`](../../docs/) | mdBook documentation sources and supporting assets. |
| [`.github/workflows/`](../../.github/workflows/) | Build, test, documentation, and release automation. |

## Production source layout

- `src/GUI/BitzArt.VS.GUI.Abstractions/` contains framework enums and dependency-light model types. Shared primitives, including [`GuiCallback`](../../src/GUI/BitzArt.VS.GUI.Abstractions/Models/Common/GuiCallback.cs), live under `Models/Common/`.
- `src/GUI/BitzArt.VS.GUI/Public/` contains the developer-facing component-tree API; `Internal/` contains its runtime implementation.
- `src/UI-Tweaks/UI-Tweaks/Gui/Dialogs/` contains the mod's GUI framework consumers and vanilla-composer dialogs.
- `src/UI-Tweaks/UI-Tweaks/ModConfig/` contains persisted configuration models grouped by feature.
- `src/UI-Tweaks/UI-Tweaks/ModFeatures/` coordinates individual mod capabilities, while `ModSystems/` contains Vintage Story lifecycle entry points.
- `HarmonyPatches/`, `Services/`, `Models/`, `HudElements/`, and `Utility/` under the mod project contain focused supporting behavior.

## Runtime feature ownership

| Feature | Responsibility |
| --- | --- |
| [`GuiDialogHostFeature`](../../src/UI-Tweaks/UI-Tweaks/ModFeatures/GuiDialogHostFeature.cs) | Initializes and owns the shared custom dialog host. It must start before host consumers. |
| [`ModConfigFeature`](../../src/UI-Tweaks/UI-Tweaks/ModFeatures/ModConfigFeature.cs) | Registers the `Shift+N` hotkey and opens the mod configuration dialog. |
| [`GameTweaksFeature`](../../src/UI-Tweaks/UI-Tweaks/ModFeatures/GameTweaksFeature.cs) | Applies or removes independent small game-behavior patches, including the calendar-year correction. |
| [`MealIndicatorFeature`](../../src/UI-Tweaks/UI-Tweaks/ModFeatures/MealIndicatorFeature.cs) | Owns the optional item-slot overlay for partially filled meal bowls and its Harmony patch lifecycle. |
| [`GameStatusFeature`](../../src/UI-Tweaks/UI-Tweaks/ModFeatures/GameStatusFeature.cs) | Owns status-value collection and the configured built-in and custom HUD labels. |
| [`QuickSearchFeature`](../../src/UI-Tweaks/UI-Tweaks/ModFeatures/QuickSearchFeature.cs) | Owns the Quick Search dialog, handbook-item index, calculator path, and `N` hotkey. |
| [`ZoomFeature`](../../src/UI-Tweaks/UI-Tweaks/ModFeatures/ZoomFeature.cs) | Owns hold-to-zoom state, rendering, projection and mouse-sensitivity patches, and the `Z` hotkey. |
