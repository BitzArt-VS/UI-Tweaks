# Reference guide

This directory stores durable, source-backed notes for Codex agents. Keep it short, easy to scan, and focused on facts that are useful across sessions.

## How to use it

1. Start with `toc.md`.
2. Open only the numbered reference files relevant to the task.
3. Follow subdirectory links when more detail is needed.
4. Read the actual source before editing; references are guidance, not a source replacement.


## How to change it

- Add or update notes when they are source-backed and useful for future agents.
- Prefer links and concise summaries over duplicated source content.
- Keep links valid when files are renamed, moved, or removed.
- `.codex` is normally protected, so edits here may require elevated approval.
