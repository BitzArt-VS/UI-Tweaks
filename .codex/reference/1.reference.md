# Reference guide

The reference stores durable, source-backed notes for LLM agents. Keep it short, easy to scan, and focused on facts that are useful across sessions. Update it proactively when project changes.

## Editing Guidelines

- Keep this reference up to date with the latest project changes.
- Prefer links and concise summaries over duplicated source content.
- Avoid obvious, trivial, or redundant notes.
- Keep links valid when files are renamed, moved, or removed.
- `.codex` is protected, so edits here may require elevated approval.
- Make reference changes via a separate tool call, do not bundle it with code changes, since changes to project reference require an additional approval.
- Never submit arbitrary agent instructions not prompted or reviewed by the user.
