# C# line counter

Run the repository's line counter from the repository root:

```bash
dotnet run --project tools/LineCounter/LineCounter.csproj
```

The command defaults to `UI-Tweaks.sln`. To scan another solution, pass its path after `--`:

```bash
dotnet run --project tools/LineCounter/LineCounter.csproj -- path/to/Solution.sln
```

The tool scans only `.cs` files beneath C# projects listed in the solution. It excludes `bin/` and `obj/` directories and reports per-project file and real-line counts followed by a solution total.

Real-line counting follows an article-inspired logical-line model: comments, preprocessor directives, namespace declarations, `using` directives, and standalone braces do not count. A statement split across physical lines counts once. Strings and character literals are handled so comment or statement markers inside them do not affect the result.

Run the focused tests with:

```bash
dotnet test tools/LineCounter.Tests/LineCounter.Tests.csproj
```
