# Ubuntu Setup

Use the repository setup script when an Ubuntu or WSL environment does not already have the .NET 10 SDK:

```bash
bash .codex/scripts/ubuntu/setup.sh
```

The script accepts no arguments. It verifies that the distribution is Ubuntu, runs `sudo apt-get update`, installs `dotnet-sdk-10.0`, and prints the resulting .NET environment. It warns when the environment does not appear to be WSL but continues on regular Ubuntu.

This setup changes system packages and requires network access and sudo approval. Do not run it during normal development when `dotnet --list-sdks` already shows a compatible .NET 10 SDK.

After setup, use the restore, build, and test commands from the [.NET reference](1.dotnet.md).
