# GUI Framework Overview

The custom GUI framework is a Blazor-inspired, Cairo-backed component system under `src/UI-Tweaks/Gui/Framework/`. Components declare keyed child trees in C# through `BuildComponentTree(IGuiTreeBuilder)`.

## Architecture

- `GuiNode` is the base for tree nodes that do not participate in layout. `GuiComponent` adds measurement and layout parameters.
- Render-tree builders own component instances and reconcile declarations by type and key.
- Reconciliation, arrangement, and painting are separate invalidation levels. Arrange walks also paint and cache bounds; paint-only walks reuse those bounds.
- `GuiDialogHost` owns framework dialogs. `DialogRenderer` connects a component tree to Vintage Story through `GuiElementAdapter`.
- Tooltips and popups use separate Cairo-backed floating layers so they can extend outside the main dialog surface.
- Mouse input is bounds-based; keyboard input is focus-based.

| Project dialogs built with the framework | `src/UI-Tweaks/Gui/Dialogs/` |
