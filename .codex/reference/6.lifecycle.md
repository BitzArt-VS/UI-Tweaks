# Lifecycle

Read this reference when changing the mod entry point, feature registration or
ordering, configuration activation timing, event or renderer ownership, Harmony
patching, or disposal.

## Startup

1. [`UiTweaksModSystem`](../../src/UI-Tweaks/ModSystems/UiTweaksModSystem.cs) is a
   client-only Vintage Story mod system.
2. It loads `ui-tweaks.json` through
   [`GetModConfig`](../../src/UI-Tweaks/Extensions/GetModConfigExtension.cs). A valid
   loaded config is stored again so newly introduced defaults are persisted. A load
   failure is logged and replaced with a newly stored default config.
3. It constructs features in dependency order. `GuiDialogHostFeature` must precede
   consumers of the shared dialog host.
4. The base [`ModSystem`](../../src/UI-Tweaks/ModSystems/Base/ModSystem.cs) filters
   features through `ShouldLoad(Client)`, then starts them in list order.

Feature startup is isolated: a feature that throws is logged and disposed without
preventing later features from starting. A failure in the mod system's own startup
path disposes the whole system.

## Activation timing

`QuickSearch.Enable` and `Zoom.Enable` are evaluated by their features'
`ShouldLoad` methods during startup. Changing either property does not add or remove
that feature from the current lifecycle, so enabling or disabling it requires a
restart.

Already-running features may handle other values live. In particular,
[`GameTweaksFeature`](../../src/UI-Tweaks/ModFeatures/GameTweaksFeature.cs) listens
for `CorrectCalendarYear` changes and applies or removes its Harmony transpiler
without a restart.

## Cleanup invariants

- The mod system attempts to dispose every feature even when another feature's
  disposal throws.
- Each feature owns cleanup for the events, renderers, dialogs, HUD elements, and
  Harmony patches it registered.
- Harmony features remove only patches belonging to their own Harmony ID.
- Zoom cleanup restores shared field-of-view and mouse-sensitivity factors to `1`.
- New features belong in the ordered feature list in `UiTweaksModSystem`; their
  partial-start cleanup and repeat-safe disposal are part of the lifecycle contract.
