# Project structure reference

Use the repository root as the working directory. The solution is defined by
[UI-Tweaks.sln](../../UI-Tweaks.sln).

| Area | Purpose |
| --- | --- |
| [`src/UI-Tweaks/`](../../src/UI-Tweaks/) | Production mod project targeting .NET 10. |
| [`tests/UI-Tweaks.Tests/`](../../tests/UI-Tweaks.Tests/) | xUnit v3 tests with access to production internals. |
| [`resources/`](../../resources/) | Vintage Story assemblies, mod metadata, localized assets, and textures used by build and packaging. |
| [`docs/`](../../docs/) | mdBook documentation sources and supporting assets. |
| [`.github/workflows/`](../../.github/workflows/) | Build, test, documentation, and release automation. |

## Production source layout

- `Gui/Framework/Public/` contains the developer-facing GUI framework API; `Gui/Framework/Internal/` contains its runtime implementation.
- `Gui/Dialogs/` contains UI Tweaks dialogs built on the GUI framework.
- `ModConfig/` contains persisted configuration models grouped by feature.
- `ModFeatures/` coordinates individual mod capabilities, while `ModSystems/` contains Vintage Story lifecycle entry points.
- `HarmonyPatches/`, `Services/`, `Models/`, `HudElements/`, and `Utility/` contain focused supporting behavior.

## Runtime feature ownership

| Feature | Responsibility |
| --- | --- |
| [`GuiDialogHostFeature`](../../src/UI-Tweaks/ModFeatures/GuiDialogHostFeature.cs) | Initializes and owns the shared custom dialog host. It must start before host consumers. |
| [`ModConfigFeature`](../../src/UI-Tweaks/ModFeatures/ModConfigFeature.cs) | Registers the `Shift+N` hotkey and opens the mod configuration dialog. |
| [`GameTweaksFeature`](../../src/UI-Tweaks/ModFeatures/GameTweaksFeature.cs) | Applies or removes independent small game-behavior patches, including the calendar-year correction. |
| [`GameStatusFeature`](../../src/UI-Tweaks/ModFeatures/GameStatusFeature.cs) | Owns status-value collection and the configured built-in and custom HUD labels. |
| [`QuickSearchFeature`](../../src/UI-Tweaks/ModFeatures/QuickSearchFeature.cs) | Owns the Quick Search dialog, handbook-item index, calculator path, and `N` hotkey. |
| [`ZoomFeature`](../../src/UI-Tweaks/ModFeatures/ZoomFeature.cs) | Owns hold-to-zoom state, rendering, projection and mouse-sensitivity patches, and the `Z` hotkey. |
